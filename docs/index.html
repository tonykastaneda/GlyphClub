A Real Cross-Platform Font Manager

Not a fancy web app wrapper.

Download for macOS Download for Windows

Built straight from source via GitHub Actions — grab the newest build from Releases.

No accounts, no logins

Point GlyphClub at a folder. However your team syncs it — Dropbox, Drive, iCloud, OneDrive, SMB — is entirely up to you, not us.

Watches, doesn't nag

Drop a font straight into a shared library and GlyphClub picks it up on its own. A manual sync button is still there for when a cloud client needs a nudge.

Real activation, both platforms

Fonts install and uninstall at the system level on macOS and Windows — not a browser tab pretending to be a font manager.
