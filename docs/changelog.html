0.1.0 — First build

🎉 New

  • Native macOS + Windows app — no browser, no Electron, no web app wrapper.
  • Point GlyphClub at any folder your team already syncs (Dropbox, Drive, iCloud, OneDrive, SMB) — no account, no OAuth.
  • A folder watcher picks up new fonts dropped straight into a shared library automatically.
  • Drag a font onto the window and choose which library to file it into.
  • Manual sync button that touches every file first, for cloud clients that need a nudge before they'll sync.
  • Real system-level font activation on both macOS and Windows.
  • Activation memory — removing and re-adding a library folder restores whatever was active in it.
  • Grid and list views, with a live sample-text preview picker.
